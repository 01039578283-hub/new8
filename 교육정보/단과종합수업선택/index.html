이 글에서 확인할 내용

01

보완할 과목과 필요한 도움부터 적기

성적이 높은 학생은 단과, 낮은 학생은 종합이라는 단순 분류로 선택하지 않습니다. 최근 과제에서 필요한 개념 설명, 질문 피드백, 일정 점검을 과목별로 적어 보세요. 한 과목만 어려워도 여러 도움을 원할 수 있고 여러 과목을 집에서 확인할 수도 있습니다.

학생의 방학 목표를 “수학 함수 조건 설명”처럼 확인 가능한 과제로 정합니다. 종합적으로 도움을 받고 싶다면 어떤 과목과 행동을 포함하는지 구체적으로 말하세요. 선택한 수업 이름 자체가 그 필요를 충족한다고 미리 판단하지 않습니다.

02

제공 범위와 실제 일정을 같은 표에 넣기

각 안내의 수강 과목·학년·횟수·기간·수업 방식과 진도 조정 여부를 기록합니다. 단과가 반드시 자유 일정이거나 종합이 반드시 고정 일정인 것은 아니므로 실제 시간표를 확인하세요. 현재 지점에서 선택 가능한 형태인지도 별도로 문의합니다.

포함된 설명, 질문 시간, 과제와 피드백의 범위를 물어봅니다. “관리”라는 말이 출결 확인인지 플래너 확인인지 개별 학습 피드백인지 구분하세요. 명칭만 보고 모든 과목의 보완과 독립 공부가 자동으로 해결된다고 생각하지 않습니다.

03

비용은 비교 조건을 먼저 맞추기

월 금액만 적기보다 수업 기간과 횟수, 교재·추가 항목을 같은 기준으로 확인합니다. 단과가 항상 종합보다 저렴하다고 단정할 수 없습니다. 여러 단과를 함께 선택하면 이동과 시간, 총비용이 어떻게 달라지는지도 계산합니다.

실제 비용·등록·변경·환불 안내는 해당 지점의 현재 조건을 확인합니다. 이 글의 비교표는 금액표가 아닙니다. 안내가 서로 다른 기간을 기준으로 적혀 있다면 비교 가능한 기간으로 바꾸어 질문하고 확정되지 않은 값은 문의 항목으로 남깁니다.

04

수업 밖의 독립 확인 시간도 비교하기

이동과 쉬는 시간, 수업 과제와 혼자 다시 할 시간을 하루 일정에 넣습니다. 여러 과목을 듣고도 설명을 적용할 시간이 부족하면 원하는 목표와 맞는지 점검하세요. 수업이 없는 날에 질문과 과제 결과를 어떻게 확인할지도 생각해 봅니다.

선택 후에는 처음 목표로 정한 과제를 다시 살펴 진도와 독립 수행을 나누어 기록합니다. 필요와 맞지 않는 부분은 지점에 질문해 분량·방식·일정을 확인합니다. 수업형식 비교 페이지와 학습가이드는 상담 질문을 만드는 참고 자료로 함께 활용할 수 있습니다.
