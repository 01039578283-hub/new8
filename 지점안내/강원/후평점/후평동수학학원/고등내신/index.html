표준 문제와 변형 문제의 조건을 나란히 적습니다. 원리가 유지되는 부분과 새로 판단할 부분을 나누고 필요한 중간값을 정리한 뒤 풀이하세요. 현재 학년뿐 아니라 선택과목 이름과 실제 평가 범위를 확인하세요. 해당 수업의 지점별 개설 범위는 상단 수강 안내에서 구분합니다. 이 페이지의 일반 예시는 실제 과목·범위·수준에 맞는 문항으로 바꾸어 활용하세요.

해설 뒤에 맞힌 답과 독립 재확인은 어떻게 구분하나요?

처음 답안·사용한 힌트·수정 이유를 지우지 않고 남깁니다. 나중에 해설 없이 첫 판단부터 다시 쓰거나 새 문장에서 근거를 설명한 결과를 따로 기록하세요.

과제와 시험 일정이 겹치면 계획을 어떻게 조정하나요?

이번 계획에서 바꿀 행동을 하나 정합니다. 다음 확인에 가져갈 답안·풀이·질문을 정해 두면 목표가 실제 과제로 연결됩니다. 실제 과제 마감과 가능한 날짜를 전달하고, 지점의 보충·특강 운영은 별도로 문의하세요.

내신 공통·기본 수강·다른 학교급 안내는 언제 선택하나요?

내신 공통은 학교 자료와 평가 전후 준비 흐름을, 이 고등 안내는 학교의 실제 과목명·선택과목·자료 범위와 중간 판단·답안 근거 기록을 확인할 때 활용하세요. 기본 안내는 과목별 대상 학년과 학습 목표를, 다른 학교급 안내는 해당 단계로 전환할 준비를 살펴볼 때 선택합니다. 실제 수업 운영은 별도로 확인합니다.

후평점 고등 내신 수업의 최종 비용은 어떻게 확인하나요?

지역 공통 참고 금액과 실제 지점 교습비를 구분하세요. 기존 표는 별도 내신반 전용 요금이 아닙니다. 실제 과목·학년·횟수·시간·교재와 추가 프로그램을 구분해 지점 교습비 자료와 상담에서 최종 금액을 확인하세요.
